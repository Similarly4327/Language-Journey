Japanse audio: v2 en v4

Dezelfde stem (Sakura), exact dezelfde kana-brontekst en hetzelfde MP3-formaat. v2 gebruikt de huidige productie-instellingen; v4 gebruikt de nieuwe Dialogue API met expliciet Japans. Geen nabewerking of trimming. Dit is een luisterproef; geen kwaliteitsgoedkeuring.

Let op de eerste klank, extra klinkers, volledige uitspraak, ritme en verstaanbaarheid. Het model gebruikt per API zijn ondersteunde instellingen; een gedeelde seed garandeert geen gelijke uitvoering.
